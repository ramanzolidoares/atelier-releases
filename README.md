# Atelier

Downloads for Atelier, a Mac app for product designers who design in code. Needs macOS 26.

## Install

1. Open the newest release under [Releases](https://github.com/ramanzolidoares/atelier-releases/releases/latest) and download **Atelier.zip**.
2. Open the zip and move **Atelier** to your Applications folder.
3. Open Atelier. It is signed and notarized by Apple, so it opens like any other Mac app.

## Updates

Atelier checks this page when it opens and every few hours. When a newer version is here, **Update Atelier** shows at the foot of the sidebar; Atelier downloads it, checks its signature, and reopens. You can also choose **Atelier > Check for Updates…**, and switch automatic checks off in **Settings > General**.
